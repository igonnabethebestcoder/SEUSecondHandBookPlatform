# SEUBookTradingPlatform  

项目成员：71122133 唐珉

**一.项目简介**

针对东南大学校内师生的二手书交易平台，师生们可根据自己的一卡通号登录进行书籍交易

**二.基础功能：**   
 **_2.1对用户：_**
 
 2.1.1.能够进行注册和登录 
 
 2.1.2.能够上传图书信息 
 
 2.1.3.能够根据书名、作者名、主题等多种方式进行查找 
 
 2.1.4.能够下单完成交易
 
 2.1.5.能够向管理员提出申诉

 2.1.6.用户间实时聊天
 
 **_2.2对管理员：_**
 
 2.2.1.能够添加图书类别
 
 2.2.2.能够进行用户管理(包括用户的增删改查)
 
 2.2.3.能够处理用户提出的申诉
 
 
模块化功能实现顺序
1.构建数据库(考虑各个不同数据间的联系)
2.创建实体类(@Entity,使用@id，@column映射数据库的主键和列)
3.创建Dao层持久层，对数据库进行操作和持久维护(@Mapper or @Repository)
4.创建service层(@Service 作为控制类，相当于边界类和实体类的沟通者)
5.创建controller(@Controller响应主界面的url请求，并实现页面跳转的逻辑和提供数据)
6.创建thymeleaf样式的html(根据controller设计url跳转逻辑)
7.测试功能是否正常
